# 評価指標ガイド

モデル予測と人手評価の比較では、誤差、変動の追従、絶対一致を別々に確認します。単一指標だけで性能を判断しないでください。

## 誤差指標

### MAE

```text
MAE = mean(|prediction - reference|)
```

平均して何点ずれているかを元スコアと同じ単位で示します。0に近いほど良好で、RMSEほど外れ誤差を強調しません。

### RMSE

```text
RMSE = sqrt(mean((prediction - reference)^2))
```

0に近いほど良好です。MAEより大幅に大きい場合、一部に大きな誤差がある可能性があります。

### Bias

```text
Bias = mean(prediction - reference)
```

負なら過小評価、正なら過大評価の傾向です。正負の誤差が相殺されるため、Biasだけでは精度を判断できません。

### R²

```text
R² = 1 - sum((reference - prediction)^2)
         / sum((reference - mean(reference))^2)
```

- 1: 完全一致
- 0: 参照値の平均を常に予測する場合と同程度
- 負: 参照値の平均より誤差が大きい

相関係数の二乗とは目的が異なります。既存予測の一致評価には上式を使います。

## 相関指標

### Pearson相関係数

直線的に同じように上下するかを-1～1で示します。平均値がずれていても高くなるため、値そのものの一致は保証しません。

### Spearman順位相関係数

順位が同じように変化するかを-1～1で示します。外れ値や非線形な単調関係に比較的頑健ですが、絶対値の一致は保証しません。

## 一致度指標

### CCC（Linの一致相関係数）

```text
CCC = 2 × covariance(x,y) /
      (variance(x) + variance(y) + (mean(x) - mean(y))²)
```

相関に加え、平均と分散のずれを考慮します。1に近いほど絶対一致が高く、0付近や負値は不一致を示します。

### ICC(2,1)

複数系列・評価者の絶対一致を、二元配置ランダム効果・単一測定として評価します。系列数は固定ではなく、比較対象すべてを列として扱います。評価対象のばらつきが小さい場合や標本数が少ない場合は不安定になります。

### Quadratic weighted kappa

1～7のような順序尺度で、離れた誤分類を強く罰する一致度です。連続値としての誤差も確認するため、MAEやRMSEと併用します。

## Bland–Altman分析

```text
Bias = mean(difference)
Lower 95% LoA = Bias - 1.96 × SD(difference)
Upper 95% LoA = Bias + 1.96 × SD(difference)
```

95%一致限界（LoA）は個々の差が入る範囲の目安であり、平均Biasの95%信頼区間ではありません。許容可能かは研究目的に応じて事前に定めた誤差幅と比較します。

## 順序分類指標

- exact accuracy: 丸めたクラスが完全一致した割合
- within 1 / within 2: 誤差が±1 / ±2以内の割合
- weighted precision / recall / F1: クラス別性能を頻度で重み付け
- confusion matrix: どの集中度同士を混同したかを確認

## 推奨する確認順序

1. 時系列・散布図でずれと外れ値を確認する。
2. MAEとRMSEで誤差量を確認する。
3. Biasで過大・過小評価を確認する。
4. PearsonとSpearmanで変動追従を確認する。
5. CCC、ICC、weighted kappaで一致度を確認する。
6. R²が0を上回るか確認する。
7. Bland–Altmanの一致限界を許容誤差と比較する。

## 集計時の注意

- 比較対象の児童、時間範囲、Window定義を揃える。
- 評価点が少ないと相関、CCC、ICCは不安定になる。
- 端数だけの最終区間は除外した感度分析も行う。
- 長時間平均は短時間変化を平滑化する。
- 人手評価者同士の一致度も確認し、参照値自体の不確実性を把握する。

## Excel互換性

古いExcelとの互換性が必要なブックでは、次の関数を使用します。

| 新形式 | 互換形式 |
|---|---|
| `RANK.AVG` | `RANK` |
| `COVARIANCE.P` | `COVAR` |
| `VAR.P` | `VARP` |
| `STDEV.S` | `STDEV` |

`openpyxl`は数式を計算しないため、生成したブックはExcelで再計算して値を確認してください。
