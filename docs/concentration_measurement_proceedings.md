# 授業映像を用いた児童の集中度推定システムの開発と予備評価

## 1．背景と目的

授業中の児童の集中状態を継続的に把握することは、授業改善や身体活動を取り入れた短時間休憩（アクティ・ブレイク：AB）の評価に役立つと考えられる。しかし、複数の児童を人手で継続して観察・評価するには負担が大きい。本研究では、授業映像から児童ごとの集中度を推定し、学級全体の時間的変化を可視化するシステムを開発した。なお、本研究の「集中度」は、映像から観察可能な授業課題への従事度として定義し、内面的な集中状態とは区別する。

## 2．方法

小学校の授業映像4データセットを用いた。人物検出・追跡にはYOLOとBoT-SORTを使用し、児童ごとに頭部から上半身の画像および17点の姿勢キーポイントを抽出した。映像を5秒区間に分割し、各区間から毎秒2フレーム、計10フレームを取得した。評価者1名による1～7の7段階評定を教師ラベルとし、画像と骨格の特徴を融合してTransformerで時間的変化を処理する順序尺度推定モデルを学習した。「聞く」「書く」「話し合う」の授業状況を特徴として利用する条件に加え、骨格の動き、クラス頻度の補正、画像拡張などの条件を比較した。

評価では、同一授業内の区間を学習用・検証用に分ける区間単位分割と、4データセットを一つずつ検証用に回す授業単位分割を実施した。指標には7段階評定の完全一致率、平均絶対誤差（MAE）、二次重み付きκ係数（QWK）を用いた。また、推定値の保存、児童内平均を経た学級全体の集計、AB前後の比較を行う機能を実装した。

## 3．結果

人物検出・追跡、評定入力、学習、動画・リアルタイム推論、時系列集計までを一連の処理として実装した。保存済みの区間単位分割の比較結果では、基準条件の完全一致率は72.0％、MAEは0.545、QWKは0.813であった。授業状況を集中度推定に入力しない条件では、完全一致率76.8％、MAE 0.469、QWK 0.829を示した。一方、同条件の授業単位分割では、4分割の完全一致率は29.6～52.5％、MAEは1.180～1.907、QWKは0.051～0.419であり、授業によって性能が異なった。これらは検証データを用いて最良の学習時点を選択した開発段階の成績であり、独立した最終評価の結果ではない。

## 4．考察

授業映像から児童ごとの課題従事度を推定し、学級全体の変化を可視化するための基盤を構築できた。一方、区間単位分割に比べて授業単位分割で性能が低下したことから、撮影条件、授業内容、姿勢や評定分布の違いへの対応が課題と考えられる。同一授業内の区間は児童や背景などを共有するため、区間単位分割の成績のみで未知授業への有効性を判断することはできない。また、教師ラベルが評価者1名に基づくため、複数評価者による一致度の検証が必要である。今後は、モデル選択に使用しない別授業・別学校での外部検証を行う。ABの評価についても、授業状況や介入直後の運動の影響を考慮し、対照条件と複数の実施例を設けて検証する必要がある。
