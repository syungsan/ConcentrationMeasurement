# iPhone縦動画からの顔登録

`capture_faces_gui.py`と`build_face_db.py`の画像処理を修正しました。

- 動画はOpenCVが対応する場合に回転メタデータを適用します。プレビューが横向きのままならGUIの「追加回転（時計回り）」で90/270度を選択してください。通常は0です。
- プレビューは画面内に縮小表示しますが、検出・保存には元解像度のフレームを使います。縦長フレーム全体で顔を検出できなければ、重なる正方形領域でも再試行します。
- 顔クロップはサイズに比例した余白を確保し、画像端ではパディングして正方形にします。顔の縦横比を変えません。保存済みjpgの番号に続けて保存し、以前の画像を上書きしません。
- 顔DB作成時の正方形への引き伸ばしを廃止し、縦横比を保って余白を追加します。固定80pxで失敗した場合は画像サイズに比例した余白でも試し、それでも失敗すれば90/270/180度を試します。変換後の画像上で検出と特徴量抽出を行います。
- 日本語のファイルパスでも読み書きできるよう、OpenCVのimdecode/imencodeを利用します。

既存画像も再キャプチャせずに新しいDB作成処理を試せます。別名へ出力すると既存DBと比較できます。

```powershell
python scripts/tools/build_face_db.py --faces_dir faces --out models/face_db_portrait.npz
```

ローカルの4人×各3枚で、従来の検出成功は6/12枚、修正後は12/12枚でした。全件で有限の顔特徴量が得られました。これはサンプル画像での確認であり、実動画からのGUI操作・全画像での検出率・本人識別の正確さは未検証です。既存の顔画像と顔DBは変更していません。幾何変換・端でのクロップ・タイル座標・回転時の再検出の4件のテストも通りました。
