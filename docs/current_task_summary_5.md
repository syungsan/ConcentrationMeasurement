## 2. プロジェクトの目的

授業動画から児童の集中度を1〜7で推定し、教室全体の時間変化や介入プログラム「アクティ・ブレイク（AB）」前後の変化を分析する。

主なモデル入力は以下の3系統。

- 5秒間の上半身画像
- 5秒間のスケルトン・キーポイント
- `聞く`、`書く`、`話し合う`などのシチュエーション確率

標準構成では2 fpsで5秒間をサンプリングするため、1人・1窓あたり10サンプルを使用する。推論時は5秒窓を1秒ずつシフトし、集中度を約1秒ごとに更新する。

## 3. 学習と推論の現在の構成

### 3.1 入力モード

- `image`: 上半身画像を使用
- `skeleton`: 姿勢キーポイントを使用
- `fusion`: 上半身画像と姿勢キーポイントを併用

### 3.2 シチュエーション特徴量

シチュエーションの記録・分類・表示機構は維持する。一方、シチュエーション確率を集中度推定へ入力するかどうかは、フラグで切り替えられる。

- 既定値: `true`
- 学習: `scripts/07_train.py --use-situation-feature` / `--no-use-situation-feature`
- オフライン推論: `scripts/09_video_offline.py --use-situation-feature` / `--no-use-situation-feature`
- 独立評価: `scripts/tools/evaluate_labeled_dataset.py --use-situation-feature` / `--no-use-situation-feature`

モデル設定は`use_situation_feature`としてチェックポイントへ保存される。

### 3.3 時系列推論

標準設定は以下。

- 時間窓: 5秒
- サンプリング: 2 fps
- サンプル数: 10
- 推論間隔: 1秒
- 窓の重複: 4秒

5秒分がそろう前は、注釈動画に`warm-up */10`と表示される。この数値は集中度ではなく、必要な10サンプルの蓄積数である。

## 4. 注釈動画の表示

`scripts/09_video_offline.py`では、初回推論前の表示を通常のscore表示と区別している。

- 表示例: `ID:3  warm-up 6/10`
- 文字色: 灰色
- 背景: 濃い灰色

直近の改修では、小さすぎたwarm-up表示を少し拡大した。

```python
font_scale=max(0.50, float(args.label_scale) * 0.66)
```

通常score表示に対する倍率を58%から66%へ変更した。既に生成済みの注釈動画には反映されないため、確認には動画の再生成が必要。

## 5. 独立評価

`scripts/tools/evaluate_labeled_dataset.py`で、学習済みモデルとラベル付きデータセットを比較する。

主な評価指標は以下。

- MAE、RMSE、Bias
- R²
- Pearson相関、Spearman相関
- exact accuracy、within 1、within 2
- weighted precision、recall、F1
- quadratic weighted kappa

評価結果の統計量は`metrics.json`へ保存される。図の日本語文字が欠けないよう、利用可能な日本語フォントを優先する処理も追加済み。

系列の変化傾向を見る場合は、絶対一致だけでなくPearson相関とSpearman相関も重視する。ただし、相関が高くても値そのものが一致しているとは限らないため、MAE、Bias、CCC、ICCなどと併せて判断する。

## 6. 人手評価との一致度分析

モデル系列`score_mean`と以下の人手評価系列を共通時間軸で比較している。

- `gold_standard`
- `bronze_standard`
- `tadano`

生の秒単位平均をさらに300秒平均すると変化が平滑化されすぎるため、目的に応じて以下を使い分ける。

- 人手評価時点との比較: 評価時点を中心とする局所平均
- 現在の標準案: ±5秒の局所平均
- 見栄え用の時系列: 移動平均
- 長時間傾向の参考: 300秒間隔の比較

評価用と見栄え用の平滑化を混同しないこと。

## 7. AB介入効果分析

`scripts/13_ab_intervention_report.py`は、推論DBからAB前後解析用のExcelレポートを生成する。

基本方針は以下。

- ABは立位・身体運動を含むため、授業中の集中度とは分離する。
- AB実施中は主要な効果量計算から除外する。
- AB終了直後にはクールダウン時間を設ける。
- 既定のクールダウンは90秒。
- AB前後は既定で各300秒を比較する。
- 5秒単位で児童内平均を求めてから教室全体を集約する。
- シチュエーション別の前後比較を行う。
- AB前のシチュエーション構成比を使った標準化効果を算出する。
- クールダウン0、30、60、90、120、180秒の感度分析を行う。

レポートのDashboardには以下を表示する。

- AB前、AB中、クールダウン、AB後を明記した集中度推移
- 未調整効果とシチュエーション標準化効果
- シチュエーション別のAB前後比較
- クールダウン設定による推定AB効果の変化

クールダウン感度グラフの横軸は「AB終了後に解析から除外する秒数」、縦軸は「標準化後のAB後−AB前の集中度差」を表す。ABイベントが1件だけの場合は因果効果を確定できず、設定感度の参考として扱う。

## 8. 教師データ追加時の学習方針

新しい教師データだけを使って既存モデルから追加学習することは可能。ただし、新規データだけに適応して過去データの性能が低下する「破滅的忘却」に注意する。

推奨運用は以下。

1. 新規データだけの追加学習で改善可能性を短時間で確認する。
2. 新旧それぞれの検証データで性能を確認する。
3. 実運用候補では、新規データと過去データの一部を混ぜたリプレイ学習を行う。
4. 節目では全学習データを統合して正式に再学習する。
5. 最終評価データは学習へ混入させない。

データ分割は重複する5秒窓単位ではなく、可能な限り児童、動画、授業日、学校などのグループ単位で行う。
