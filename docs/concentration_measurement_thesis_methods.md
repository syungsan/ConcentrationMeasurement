# 2．研究方法

## 2.1　集中度の定義と授業映像の撮影

本研究では、授業中の児童がその時点の課題や活動にどの程度取り組んでいるかを、映像から観察できる行動に基づいて評定し、これを「集中度」とした。集中度は1点から7点までの順序尺度で表し、得点が高いほど授業課題への従事度が高いことを示す。児童ごとの短時間の集中度を推定するモデルを構築し、その出力を集計して、学級全体の集中度の時間的変化を評価した。

授業の撮影にはiPhoneの4K動画撮影モードを使用した。教室の前方を向いたときの左側から、教室全体と児童の着席範囲が画角に入るように撮影した。窓からの光で児童の顔や上半身が暗く写ることを避けるため、撮影前に画面を確認し、逆光を避けられるようにカメラの向きを調整した。授業単位の交差検証では、4件の授業映像からそれぞれ約10分間を切り出して用いた。

## 2.2　人物追跡と入力データの作成

授業映像に対し、YOLOで人物を検出し、BoT-SORTでフレーム間の検出結果を対応付けた。同じ児童の画像と姿勢を時間順に取り出せるように、映像内で人物ごとに追跡IDを割り当てた。その後、映像を重複しない5秒区間に分割し、各区間で一定以上の割合で検出された人物について、**児童1人の5秒区間**を一つの学習サンプルとした。

各区間内では0.5秒間隔でフレームを抽出し、標準設定では5秒当たり10フレームを使用した。各フレームから、追跡対象の頭部から上半身を含むRGB画像を切り出した。また、YOLOの姿勢推定モデルを用いて、鼻、肩、肘、手首、股関節など17点のキーポイントを取得した。各点について画像上の座標 `(x, y)` と検出信頼度を保持した。上半身画像とキーポイントを同じ児童・同じ時刻で対応付け、5秒分を時刻順に並べてモデルに入力した。したがって、教師ラベルと推定値の基本単位は5秒であり、モデルはその区間内の姿勢や動きの変化を利用できる。

## 2.3　姿勢のハンドクラフト特徴量

骨格データからは、児童の姿勢やその変化を表すハンドクラフト特徴量を作成した。まず、左右の肩の中点を基準とする各キーポイントの相対座標を計算し、左右の肩の間隔でスケールをそろえた。これにより、画面内の位置や人物の見かけの大きさの影響を抑えながら、頭部が肩に対して左右や上下にどの程度ずれているかを表現した。

次に、連続するフレーム間で相対座標の差を求め、同一区間内での頭部や腕などの移動を表した。さらに、左右の肩を結ぶ方向、肩と股関節を結ぶ方向、上腕・前腕の方向、肩から鼻への方向を単位ベクトルとして求めた。これらの特徴を組み合わせることで、例えば、上体の傾き、頭部と体幹の位置関係、腕の配置、およびそれらの時間的変化を入力に反映した。検出信頼度が低い点を含む座標差や方向ベクトルは、計算に必要な点がそろう場合のみ有効とした。

## 2.4　教師ラベルの付与

授業映像を確認しながら集中度を付与するため、専用のラベリングアプリを開発した。アプリでは、映像上の追跡IDで対象児童を確認し、該当する時間区間の行動を見ながら、集中度を1～7点で入力できるようにした。入力した評定は、対象児童、時間区間、評価者に対応付けて保存した。遮蔽などで行動を判定できない場合は、その区間をスキップできるようにした。保存済みの授業単位交差検証では、評価者1名の評定を教師ラベルに用いた。

ラベルの保存単位は5秒である。アプリには連続する複数の基本区間をまとめて表示・採点する機能があり、まとめて入力した評定は、対応する5秒区間に展開して保存される。そのため、5秒ごとに個別に採点した場合と、複数区間に同じ評定を付与した場合は、採点手続きとして区別した。

## 2.5　時系列モデルの構築と学習

骨格と画像には、それぞれ異なる特徴抽出器を用いた。骨格側では、キーポイントまたはハンドクラフト特徴量を多層パーセプトロン（MLP）に入力し、各フレームの姿勢を特徴ベクトルに変換した。画像側では、ImageNetで事前学習したResNet-18を特徴抽出器として転移学習し、上半身画像を特徴ベクトルに変換した。両者を用いる融合モデルでは、同一時刻の骨格特徴と画像特徴を結合し、時刻順に並べた系列に位置情報を加えてTransformerエンコーダに入力した。Transformerで区間内の複数時刻の情報を統合し、児童ごとに5秒区間の集中度を推定した。順序尺度を扱うため、出力部では集中度が1点から6点までの各境界を上回る確率を学習し、その結果から1～7点の範囲の推定スコアを求めた。

画像を用いる学習条件の一部では、照明や撮影方向の違いに対応するため、上半身画像の明るさ・コントラストをランダムに変化させた。標準の拡張設定では左右反転も行い、画像と骨格を併用する場合には、骨格の横方向の座標を反転させたうえで左右の関節番号を交換した。変換の有無や強さは5秒区間ごとに決め、区間内の全フレームに共通して適用した。これにより、フレーム間で変換条件が変わることによる見かけ上の動きや明るさの変化を抑えた。ランダムな拡張は学習時に適用し、検証・推論時は入力サイズの調整と正規化などの前処理を行った。交差検証では、画像拡張を適用しない条件も扱った。

学習中は、エポックごとの学習損失と検証損失、検証データでの完全一致率などを記録した。履歴をCSVと学習曲線として保存し、損失の推移と検証性能を確認した。保存済みの授業単位交差検証では、検証データでの完全一致率を基準にチェックポイントを選択した。

## 2.6　授業単位の交差検証と推定精度の評価

4件の約10分の映像のうち1件を取り置き、残る3件でモデルを学習した。取り置く映像を順に入れ替え、全4件がそれぞれ1回ずつ検証用となるようにした。この分割により、同一映像の別時刻に現れる児童や同じ教室背景が学習側と検証側にまたがることを防いだ。保存済みの実験では、取り置いた映像の評定をチェックポイントの選択にも使用しているため、この成績は**授業単位の交差検証成績**として扱った。モデル開発から独立した未知授業での評価は次節に分けた。

精度の評価では、モデルの推定スコアを1～7の整数クラスに丸め、人手による評定との点差に基づいて以下の指標を算出する。

- **完全一致率（exact accuracy）**は、予測クラスと人手評定が一致したサンプルの割合である。
- **1点以内一致率（within-1 accuracy）**は、両者の差の絶対値が1点以下であった割合である。
- **2点以内一致率（within-2 accuracy）**は、両者の差の絶対値が2点以下であった割合である。

混同行列では、人手評定を行、予測クラスを列として件数を集計し、隣り合う点数への誤りや、低得点・高得点に偏る傾向を調べる。加えて、丸める前のスコアに対する平均絶対誤差（MAE）で平均的な点差を示し、二次重み付きκ係数（QWK）で評定の順序と誤りの大きさを考慮した一致度を評価する。Pearsonの相関係数とSpearmanの順位相関係数を用いて、点数の増減や順位がどの程度対応するかも調べる。授業間の違いを把握できるよう、各指標は検証映像ごとに示す。

## 2.7　未知の授業全体における人手評定との比較

最終評価では、学習やチェックポイントの選択に用いていない別の授業映像に対し、学習済みモデルを授業の開始から終了まで適用する。人手評定では、教職経験のある教員と、評価者として参加する学生が授業映像を見て集中度を評定する。5分ごとの共通の評価区間を設け、教員の評定、学生の評定の平均値、モデルの推定値を、同じ時間軸上の3系列として比較する。

人手評定が**各5分間全体**を対象とする場合、モデルの出力も同じ5分間に対応させる。まず、該当区間内の推定スコアを児童ごとに平均し、次に児童間で平均して学級の推定スコアを求める。この集計により、追跡されている時間が長く、推定回数の多い児童に学級平均が偏ることを抑える。学生の評定は区間ごとに評価者間で平均し、各区間について有効な学生評定数とモデル集計に含まれた児童数を記録する。

3系列を折れ線グラフに重ね、集中度が上がった区間や下がった区間、モデルと人手評定が大きく離れた区間を確認する。モデルと教員、モデルと学生平均、教員と学生平均の各組について、対応する区間のPearson相関係数、Spearman順位相関係数、MAEを算出する。相関係数は時間に伴う変動の追従を、MAEは点数水準の近さを評価するために用いる。あわせて、モデルと人手評定の平均差を求め、継続的に高めまたは低めに推定する傾向を確認する。教員と学生平均の比較は、人手評定同士でもどの程度の差が生じるかを把握するために用いる。
