# 集中度予測・Gold Standard一致度評価タスクの要約

## 1. タスクの目的

教室映像から回帰モデルで推定した集中度 `score_mean` と、人間が採点した `gold_standard`、`bronze_standard` を共通の時間軸で可視化し、機械学習モデルの予測精度と人手評価との一致度を定量的に評価する。

加えて、介入後の集中度変化をモデルが十分に捉えられているか、予測値の変動幅が人手評価より小さい原因を検討する。

## 2. 入力データ

使用したCSV：

```text
outputs/019f8ee8-9b86-7b50-881b-60f28d53a92b/agg_timeseries_sec.csv
```

主要列：

- `situation`：状況区分
- `sec`：モデル予測の時間（秒）
- `score_mean`：回帰モデルによる集中度予測の平均
- `sec_standard`：人手評価の時間（秒）
- `gold_standard`：主たる人手評価
- `bronze_standard`：比較用の人手評価

`golden_standard` という表記は廃止し、`gold_standard` に統一した。

## 3. 時系列グラフ

### 3.1 グラフ形式

次の3系列を、数値の `time (sec)` を横軸とするExcelネイティブグラフとして作成した。

- `score_mean`
- `gold_standard`
- `bronze_standard`

通常の折れ線グラフでは横軸がカテゴリとして等間隔に扱われるため、秒数を正確に反映できる散布図を採用した。

### 3.2 score_meanの処理

同じ秒に複数の `score_mean` が存在する場合は、その秒の平均値を使用した。

グラフ上では、`score_mean` のマーカーを小さくし、時系列の変化を確認しやすい表示に調整した。`gold_standard` と `bronze_standard` は基準値間を線で結んで表示している。

## 4. 300秒区間での評価

人手評価は0、300、600、…、2700秒の10点であるため、モデル値を300秒区間ごとに集約して比較した。

処理手順：

1. 同じ秒に複数のモデル値がある場合、秒単位で平均する。
2. 秒単位平均を300秒区間で再平均する。
3. 各区間の `score_mean_300s` を、対応するstandardと比較する。

区間は次のように設定した。

```text
0–299, 300–599, ..., 2400–2699, 2700–2707
```

最終区間は8秒分しかないため、他の300秒区間より不確実性が大きい。

## 5. 実装した評価指標

### ペアごとの評価

次の3組について評価した。

- `score_mean` vs `gold_standard`
- `score_mean` vs `bronze_standard`
- `gold_standard` vs `bronze_standard`

評価指標：

- N
- MAE
- RMSE
- Bias（第1系列－第2系列）
- Pearson相関係数
- Spearman順位相関係数
- CCC（Linの一致相関係数）
- R²（予測一致としての決定係数）

### 3系列全体の評価

- ICC(2,1)：二元配置ランダム効果、単一測定、絶対一致

### Bland–Altman関連

- Bias
- Lower 95% limit
- Upper 95% limit

95%一致限界は次式で計算している。

```text
Lower 95% limit = Bias - 1.96 × SD(difference)
Upper 95% limit = Bias + 1.96 × SD(difference)
```

これは平均値の95%信頼区間ではなく、個々の差に対する一致限界である。

## 7. 現在の主な評価結果

300秒区間10点を用いた主な結果：

| 指標 | score vs gold | score vs bronze | gold vs bronze |
|---|---:|---:|---:|
| MAE | 0.6937 | 0.8408 | 0.3822 |
| RMSE | 0.8362 | 1.0223 | 0.4513 |
| Bias | -0.5404 | -0.7759 | -0.2356 |
| Pearson r | -0.4695 | -0.6608 | 0.7792 |
| Spearman rho | -0.5308 | -0.6229 | 0.7023 |
| CCC | -0.0987 | -0.0937 | 0.7197 |
| R² | -1.1128 | -2.0741 | 0.4010 |

3系列全体：

```text
ICC(2,1) = 0.1744
```

### 結果の概略

- `score_mean` は両standardより平均的に低い。Biasが負である。
- `score_mean` と両standardの相関は負で、上下変動の対応が弱い。
- `score_mean` と両standardのCCCは0付近の負値で、値そのものの一致度も低い。
- `score_mean` のR²は負であり、現状の300秒区間評価では、standardの平均を一定値として予測する場合より誤差が大きい。
- `gold_standard` と `bronze_standard` の相関・CCC・R²は比較的高く、人手評価同士には一定の対応がある。
- ICCは低く、3系列全体の絶対的一致度は弱い。

ただし、評価点が10点しかないこと、最終区間が8秒しかないことから、結果の不確実性は大きい。

## 8. 予測値の変動幅が小さいと考えられる原因

### 8.1 評価対象者の不一致

- `gold_standard` など：児童約8人を採点
- `score_mean`：教室全体約24人を検出して平均

介入効果が主に8人に現れ、残り16人が変化しない場合、24人平均では変化量が約 `8/24 = 1/3` に希釈される可能性がある。

### 8.2 大人数平均による分散の縮小

24人を平均すると、個人差や一時的変動が相殺される。8人平均より24人平均の方が統計的に変化幅が小さくなりやすい。

### 8.3 回帰モデルの平均への縮小

MSEなどで学習した回帰モデルは、入力から判断しにくい場合に学習ラベルの平均付近を出しやすい。

起こりやすい条件：

- 中程度の集中度ラベルが多い
- 高集中・低集中のサンプルが少ない
- 人手ラベルにノイズがある
- 正則化が強い
- 入力特徴が集中度を十分に説明できない

### 8.4 個人差

姿勢、動作量、顔の向きと集中度の関係は児童ごとに異なる。全児童に同一の絶対尺度を適用すると、予測が中央へ集まりやすい。

### 8.5 検出・追跡品質

- 遮蔽
- 後方児童の解像度不足
- 人物IDの入れ替わり
- 一時的な未検出
- 信頼度の低い推定

これらが全体平均へ含まれると、変化が平滑化される可能性がある。

### 8.6 時間平均による平滑化

300秒平均では、数十秒程度の短い介入効果が薄まる。例えば60秒だけ2点上昇しても、300秒平均への寄与は約0.4点になる。

### 8.7 standardの時刻定義との不一致

standardが瞬間評価、直前5分評価、次の5分評価のどれなのかによって、対応させるモデル区間が異なる。採点プロトコルとの整合確認が必要である。

## 9. 優先度の高い改善策

### 9.1 同じ8人だけで比較する

最優先事項。人手評価対象の8人とモデル側の人物IDを対応付け、同じ8人のモデル平均を作成する。

比較すべき系列：

- 採点対象8人のモデル平均
- 教室全体24人のモデル平均
- `gold_standard`
- `bronze_standard`

これにより、モデル自体の問題と、対象人数による希釈を切り分けられる。

### 9.2 介入対象群と非対象群を分ける

介入前後の変化をそれぞれ計算し、差の差を確認する。

```text
介入効果 = 対象群の前後差 - 非対象群の前後差
```

### 9.3 時間窓を比較する

10、30、60、120、300秒の窓で評価し、介入効果が最も明確かつ安定して見える時間幅を確認する。

### 9.4 個人内変化を使う

個人の通常状態からの差を評価する。

```text
個人内変化 = 現在の予測値 - 介入前の個人平均
```

絶対スコアよりも介入変化を捉えやすい可能性がある。

### 9.5 学習方法の改善

- 極端な集中度ラベルのサンプルを増やす
- ラベル分布に応じた重み付き損失
- Huber loss、MAE、CCC lossなどの検討
- 順序回帰
- 個人差を考慮した階層モデル
- 時系列モデルによる変化量予測

### 9.6 キャリブレーション

変化方向は合っているが振幅だけが小さい場合、独立した検証データで次の補正を学習できる。

```text
calibrated_score = a + b × predicted_score
```

ただし、対象児童と時間窓を揃える前に単純な振幅拡大を行うべきではない。

## 10. 次に推奨する分析

1. 採点対象8人をモデル側で特定する。
2. 同じ8人のモデル平均を再計算する。
3. 8人平均と24人平均の標準偏差・振幅を比較する。
4. 30秒、60秒、300秒で介入前後差を比較する。
5. 最終8秒区間を除いた9区間でも評価指標を再計算する。
6. 個人別の介入前後変化を確認する。
7. 対象を揃えても振幅が小さい場合、学習データ・損失関数・キャリブレーションを見直す。
